# 使用场景预设

预设提供一套可修改的字段配置，不会创建或批量更新文档。

## 内置预设

以下为中文界面应用预设时的字段名称：

| 预设 | 分组 | 展示字段 |
| --- | --- | --- |
| 空白看板 | 不分组 | 仅标题 |
| 任务管理 | 状态 | 负责人、截止日期、优先级 |
| 项目管理 | 负责人 | 状态、截止日期、预算 |
| 内容计划 | 发布平台 | 发布时间、标签、已发布 |

所有预设默认以文件名为标题。

任务管理预设提供“待办、进行中、已完成”的初始列顺序。开启隐藏空列后，没有文档的列会隐藏；整个看板没有文档时仍保留一个可用于新增的列。

## 在哪里应用

- **创建看板时**：在“场景预设”中选择。
- **配置全局默认时**：打开“默认字段配置”，在弹窗中应用预设并保存。
- **修改已有看板时**：打开该看板的“配置字段”，应用预设并保存。

应用后可以改分组、改标题、替换属性、增删字段或调整顺序。预设并不锁定布局。

## 与现有文档对应

如果已有文档使用 `status`、`dueDate` 等不同属性名，应把预设字段改为实际属性，不需要重命名所有文档。

例如，任务文档可以包含：

```yaml
---
状态: 待办
负责人:
  - 张三
截止日期: 2026-11-01
优先级: 高
---
```

切换界面语言不会更改已有字段。英文界面应用预设时会使用对应英文属性名，应在保存前核对。

## 切换前确认

切换预设会替换配置草稿中的分组、标题、展示字段和初始列顺序。不会更改筛选器、模板或文档正文。未保存前可以取消；保存后可再次配置，但没有独立的“撤销上一次预设”按钮。

需要保留自己的布局时，先备份 `.base` 文件。
