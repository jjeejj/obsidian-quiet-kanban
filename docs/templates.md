# Link a Document Template

A template is an existing Markdown note in your vault. When creating a card, the plugin copies its body and properties. Edit the source template using the normal note editor.

## Prepare a Template

For example, create `Templates/Task Template.md`:

```markdown
---
Owner: []
Priority: Medium
Tags:
  - Task
---

## Description

## Acceptance Criteria

- [ ] Accepted
```

Template property names should match the board's fields. They are not automatically translated or renamed to match a preset.

## Global Template

1. Open **Settings → Quiet Kanban → Global new item template**.
2. Click **Choose template** and search for an existing note, or enter its vault-relative path.
3. Boards without a local template setting use this template.

**Clear association** removes only the global setting. It neither deletes the template file nor clears independent board templates.

## Per-Board Template

Use any column's **+ → Link template…** to search for a note. The association belongs to the current board view and applies to all its columns.

You can also configure **New item template** in Bases view options.

| Board configuration | Template used for new documents |
| --- | --- |
| No local template setting | Global template |
| Local template linked | That board's template |
| Unlink template selected | No template, even if a global template exists |

## Create from the Template

1. Click **+** in the destination column.
2. Choose **Create document from linked template**.
3. Name and edit the document in the native Bases creation interface.

Property precedence is:

1. The destination column's grouping value.
2. Properties generated by the native Bases creation flow, including filters.
3. Default properties from the template.

An Ungrouped column does not inherit the template's value for the grouping property. Other template properties and its body are copied.

## Open or Unlink

**Open linked template** opens the source note. Later template edits affect future documents only, not documents already created.

**Unlink template** changes the current board's association without deleting the file.

## Supported Content

- Markdown bodies and YAML properties represented as an object.
- Missing templates and invalid properties stop creation with a notice before a new document is created.
- Content is copied as written. Variables such as `{{date}}` and `{{title}}` are not expanded, and Templater scripts are not executed.
- Check and relink paths after moving or renaming a template.
