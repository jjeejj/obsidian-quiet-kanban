# Quiet Kanban Documentation

Quiet Kanban is a custom board view for Obsidian Bases. Each card represents a document in your vault. Columns come from a selected property, and you can configure the fields shown on cards.

## Recommended Reading Order

Follow these guides to complete the setup and daily workflow:

1. [Install the plugin](installation.md).
2. [Create a board](create-board.md), or [convert an existing board](convert-board.md).
3. [Understand global and per-board configuration](configuration.md).
4. [Choose a scene preset](presets.md), then [adjust the fields](fields.md).
5. [Link a document template](templates.md).
6. [Create and manage cards](cards.md), and [open or collapse details](preview.md).
7. When updating later, read [Updates and Recovery](updates-and-backups.md).

## Complete a Minimal Workflow

1. Prepare a `Tasks` folder in your vault.
2. Install and enable Quiet Kanban and Bases.
3. Run **Create enhanced Kanban board**, set the folder to `Tasks`, and choose **Task management**.
4. Use a column's **+ → New document**. To use a template, link one first, then choose **Create document from linked template**.
5. Name the new document and fill in its owner, due date, and other properties.
6. Click its card to open details, then click the same card again to collapse them.
7. Drag the card to another column and check that its grouping property changed.
