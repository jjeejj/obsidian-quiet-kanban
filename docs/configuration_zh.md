# 全局配置与看板配置

本篇说明设置在哪里，以及多个配置如何生效。字段本身的设置见[字段配置](fields_zh.md)。

## 全局设置

入口：**设置 → Quiet Kanban**。

| 设置项 | 用途 |
| --- | --- |
| 语言 | 跟随 Obsidian、中文或 English |
| 默认字段配置 | 全局的分组、标题、展示字段及场景预设 |
| 全局新建需求模板 | 未单独设置模板的看板使用的模板 |
| 隐藏空状态列 | 隐藏当前没有文档的已配置列 |
| 详情打开方式 | 右侧分栏或新标签页，复用同一看板的详情页 |
| 再次点击同一需求时收起详情 | 是否允许再次点击同一卡片关闭详情 |
| 默认列宽 | 220–520px，默认 310px |
| 卡片背景浓度 | 0–35%，默认 17% |
| 分组颜色 | 按分组值配置颜色 |

普通开关和输入在修改后保存。“默认字段配置”弹窗中的修改需要点击“保存”；点击“取消”会丢弃草稿。

## 单个看板设置

字段布局入口：

- 首列标题旁的“配置字段”图标。
- 命令面板中的“Quiet Kanban: 配置看板字段”。

其他选项可通过 Bases 的视图选项设置，包括分组字段、标题字段、展示字段来源、模板、列宽、空列和详情打开方式。

## 优先级与继承

单看板明确配置的选项优先于全局默认。展示字段列表整套覆盖，不会与全局列表混合。

新建看板选择“使用全局默认”时，会把当时的字段布局复制进该看板。因此，之后修改全局字段布局，不会自动替换这些已保存的布局。没有单独配置的其他选项仍读取全局默认。

模板的继承独立于字段布局：没有配置本地模板时使用全局模板；在看板菜单中“取消关联模板”会明确禁用该看板的模板，即使全局已有模板。

## 列顺序

拖动列标题即可调整顺序，按看板自动保存，切换文档或重新打开后仍保留。它与 Bases 排序独立，后者控制列内卡片排列。详见[调整列顺序](cards_zh.md#调整列顺序)。

## 语言

默认跟随 Obsidian：中文环境使用中文，其他语言使用英文。也可手动选择中文或 English。

语言切换会刷新界面，不会重命名已有文档属性。预设在应用时生成的属性配置也不会随着语言切换自动改名。

## 分组颜色

在“分组颜色”区域中直接操作：

1. 已有分组：使用该行的下拉框选择颜色。
2. 新增映射：填写与实际列值一致的分组名称，选择颜色，再点击“添加”。
3. 点击“移除”只取消这条颜色映射，分组和文档仍保留，并恢复自动配色。

支持蓝、紫、青、绿、橙、粉、黄、红八种颜色。选择后自动保存。未显式配置的分组会获得稳定的自动颜色。
