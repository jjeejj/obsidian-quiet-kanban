# 新建看板

本篇说明如何创建一个 Quiet Kanban `.base` 文件。

## 创建前准备

先确定看板要显示哪些文档。建议把同一类文档放在一个文件夹中，例如 `Tasks` 或 `Projects/App`。

创建表单中的文件夹必须已经存在。该字段用于限定看板查询范围。

## 选择创建入口

- **文件夹右键 → 创建看板**：把看板文件创建在选中的文件夹，并默认查询该文件夹。
- **命令面板 → Quiet Kanban: 创建增强看板**：把看板文件创建在仓库根目录。
- **设置 → Quiet Kanban → 创建增强看板**：同样在仓库根目录创建。

“文档所在文件夹”可输入路径或从提示列表选择。它只控制看板显示的文档范围，不改变上述创建位置。

## 创建步骤

1. 通过上述任一入口打开创建表单。
2. 选择“场景预设”。
3. 填写看板文件名，例如 `任务看板`。不要包含文件夹分隔符；可以省略 `.base` 后缀。
4. 填写“文档所在文件夹”，例如 `Tasks`。留空时查询整个仓库中的 Markdown 文档。
5. 点击“创建”。插件会创建并打开看板。

看板文件按创建入口确定的位置保存。若该位置已有同名文件，会自动添加数字后缀。之后可通过 Obsidian 文件管理器移动看板文件。

## 选择初始配置

- **使用全局默认**：把当前全局字段布局复制到新看板。
- **任务管理 / 项目管理 / 内容计划**：使用对应的字段预设。
- **空白看板**：不指定分组字段，只显示文档标题。

预设不会创建文档属性，也不会批量修改已有笔记。预设中字段的实际名称可以在保存看板后调整。

如果新看板使用了英文界面的预设，生成的属性名也会使用对应英文词条。应确认它们与现有文档的实际属性名一致。

## 创建后的检查

1. 确认显示的文档范围正确。
2. 点击首列标题旁的“配置字段”图标，检查分组和标题字段。
3. 按需调整展示字段，点击“保存”。
4. 如果要套用模板，再[关联模板](templates_zh.md)。

列上的“＋”使用 Bases 的原生新建流程。实际新笔记的存放位置由该流程决定；创建后可检查路径，必要时通过卡片菜单移动文档。
