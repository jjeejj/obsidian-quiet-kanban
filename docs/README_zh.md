# Quiet Kanban 使用文档

Quiet Kanban 是 Obsidian Bases 的自定义看板视图。卡片对应仓库中的文档，列由选定属性的值生成，展示字段可以自由配置。

## 推荐阅读顺序

首次使用可以按下列顺序完成整个流程：

1. [安装插件](installation_zh.md)。
2. [新建看板](create-board_zh.md)，或[转换已有看板](convert-board_zh.md)。
3. [了解全局配置与看板配置](configuration_zh.md)。
4. [选择场景预设](presets_zh.md)，再[调整字段](fields_zh.md)。
5. [关联文档模板](templates_zh.md)。
6. [新增和管理卡片](cards_zh.md)，[打开和收起详情](preview_zh.md)。
7. 后续需要更新时，阅读[更新与备份恢复](updates-and-backups_zh.md)。

## 完成一个最小流程

1. 在仓库中准备 `Tasks` 文件夹。
2. 安装并启用 Quiet Kanban 和 Bases。
3. 执行“创建增强看板”，文件夹填写 `Tasks`，场景选择“任务管理”。
4. 点击列上的“＋ → 新建文档”。如果使用模板，先关联模板，再选择“使用关联模板新建文档”。
5. 给新文档命名，填写负责人、截止日期等属性。
6. 点击卡片打开详情，再点击同一卡片收起。
7. 拖动卡片到另一列，检查分组属性已更新。
