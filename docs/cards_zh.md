# 新增和管理卡片

卡片对应实际文档。编辑、移动或删除卡片会操作仓库文件，不只是改变看板上的显示。

## 新增文档

1. 点击目标列的“＋”。
2. 选择“新建文档”，或“使用关联模板新建文档”。
3. 在原生新建界面中命名和编辑。

新文档会写入目标列的分组值。没有分组字段时，不会额外写入分组属性。模板用法见[关联文档模板](templates_zh.md)。

## 快捷编辑

把鼠标移到卡片上，点击铅笔图标：

1. 按字段配置编辑标题和展示属性。
2. 点击“保存”，或按 `Cmd/Ctrl + Enter` 提交。
3. 点击“取消”或按 `Esc` 放弃草稿。

| 字段 | 编辑行为 |
| --- | --- |
| 文件名标题 | 重命名文档 |
| 普通笔记属性 | 更新相应属性 |
| 列表 | 每行一个值 |
| 日期 | 使用原生日期选择器点选，或输入 `YYYY-MM-DD` |
| 数字 | 校验并保存为数字，支持 `0` |
| 复选框 | 保存为布尔值 |
| 公式、文件元数据 | 只读 |

只更新有变化的字段。无关属性和文档正文保留。校验失败时草稿会留在卡片中，可修改后再次保存。

## 跨列拖动

把卡片拖到另一列，会更新当前“分组字段”。

- 标量属性改为目标值。
- 列表属性移除来源值、加入目标值，保留其他值。
- 移到“未分组”列时清除对应来源值。
- 数字和布尔值保留原类型。

只有 Markdown 文档的普通笔记属性支持此操作。公式或文件属性分组不可拖动写入。

卡片在同一列内的顺序由 Bases 排序决定，不支持通过拖动自由调整列内顺序。

## 调整列顺序

拖动列标题可重新排列有分组值的列。顺序自动保存在看板文件中，无需另点保存，切换文档或重新打开看板后仍会保留。该顺序只属于当前分组字段；改为另一分组字段时，不套用之前字段的列顺序。

没有文档的列是否显示，由“隐藏空状态列”设置决定；列还需要有已保存的分组值，例如预设提供的初始列。

## 重命名、移动和删除

点击卡片的“…”菜单：

- **重命名**：输入新的文件名，不要包含路径分隔符。
- **移动到文件夹**：填写仓库中已有的文件夹；留空移到根目录。
- **删除**：确认要删除的文档名称后，再点击删除。

移动和重命名会检查目标位置是否存在同名文件。删除按 Obsidian 的删除设置处理，是否能从回收站恢复取决于该设置。

如果移动或编辑后不再满足筛选条件，文档会从当前看板消失，文件不一定被删除。先用 Obsidian 搜索定位文档。
