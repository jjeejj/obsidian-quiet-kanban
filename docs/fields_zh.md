# 配置分组和展示字段

本篇说明如何把看板用于不同类型的文档，不必依赖固定的“状态、日期、项目”字段。

## 打开配置

点击首列标题旁的配置图标，或执行“Quiet Kanban: 配置看板字段”。全局默认布局在“设置 → Quiet Kanban → 默认字段配置”中设置。

先选择预设，或直接修改下面的配置。修改后点击“保存”。

## 分组字段

列由分组属性的值生成。例如：

| 分组属性 | 得到的列 |
| --- | --- |
| 状态 | 待办、进行中、已完成 |
| 负责人 | 各负责人 |
| 发布平台 | 各平台 |
| 是否完成 | false、true |

留空时，所有文档放在同一列。没有分组值的文档放入“未分组”。列表属性包含多个值时，同一文档可以出现在多个列中，因此列计数之和可能超过文档总数。

本插件的“分组字段”决定列的含义。Bases 的筛选和排序继续生效，但其原生分组菜单不是本插件分组字段的配置入口。

分组可以是笔记属性、文件属性或公式。后两类是只读分组，列内新增按钮和跨列拖拽写入不可用。

## 标题字段

默认 `file.name`，即文件名。可以选择其他属性；标题值为空时仍回退到文件名。标题以纯文本显示。

## 展示字段列表

选择“自定义字段列表”后：

1. 点击“添加字段”。
2. 输入属性名，或用“选择属性”搜索已有属性。
3. 选择显示样式，按需设置显示名称、空值处理。
4. 使用上下箭头排序，“移除”删除展示项。
5. 保存。

移除展示项只会让卡片不再显示该属性，不会删除文档中的属性。

属性名示例：`负责人`、`note.owner`、`file.ctime`、`formula.total`。不带来源前缀的名称按笔记属性处理。

| 选项 | 用途 |
| --- | --- |
| 显示名称 | 卡片上的别名；留空使用属性显示名 |
| 显示字段名 | 是否同时显示标签 |
| 隐藏空值 | 属性没有值时不显示该行 |
| 显示占位 | 空值显示自定义文案，未填文案时显示“未设置” |

`0` 和 `false` 都是有效值，不按空值隐藏。

## 显示样式

| 样式 | 适合内容 |
| --- | --- |
| 自动 | 按 Bases 返回的值类型选择展示 |
| 文本 | 文本或简短说明 |
| 标签样式 | 人员、项目、标签；列表中的值逐项显示 |
| 日期 | 日期字段 |
| 数字 | 金额、数量等数字 |
| 复选框 | 布尔值 `true` / `false` |

选择样式不会批量转换已有数据。日期、数字和复选框应使用相应的文档属性类型；快捷编辑保存时会对修改后的值进行处理和校验。

## 跟随 Bases 属性菜单

如果希望使用 Bases 自带的字段选择与排序，将“展示字段来源”设为“跟随 Bases 属性菜单”。

之后在工具栏“属性”中选择和排序，卡片会跟随该列表，并使用原生显示名称。标题字段不会重复出现在正文属性中。此模式不再使用自定义展示列表。

## 示例

项目看板可以按 `note.负责人` 分组，并依次展示：

1. `note.状态`：标签样式。
2. `note.截止日期`：日期，显示名称“到期”。
3. `note.预算`：数字。
