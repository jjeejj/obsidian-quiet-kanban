# 打开和收起详情

本篇说明卡片点击后的详情行为。

## 选择打开方式

在“设置 → Quiet Kanban → 详情打开方式”，或当前看板的视图选项中选择：

- **右侧分栏**：在看板右侧打开详情。
- **新标签页**：使用标签页显示详情。

同一个看板会复用自己的详情页，不会为每张卡片都创建新的详情窗口。

## 普通点击

1. 点击卡片，打开对应文档。
2. 点击另一张卡片，在同一详情页切换文档。
3. 开启“再次点击同一需求时收起详情”后，再点一次当前卡片就收起。

关闭再次点击收起的选项后，再次点击当前卡片只会继续打开或聚焦其详情。

## 其他收起方式

- 点击详情页顶部左侧、前进后退按钮之前的收起按钮。
- 执行“Quiet Kanban: 收起看板需求详情”。

收起后，焦点回到对应看板。该命令在当前看板或它的详情页处于最近活动状态时使用。

## 修饰键和键盘

- `Cmd`、`Ctrl` 或 `Shift` 加点击：使用标签页模式，本次点击不执行再次点击收起。
- 卡片获得键盘焦点后，按 `Enter` 或空格：按普通点击处理。
- 铅笔和“…”按钮执行各自操作，不打开或收起详情。

## 手动导航保护

如果在插件管理的详情页中跳转到其他文档，插件会解除对该页面的接管。后续点击卡片不会覆盖或关闭这个已用于其他用途的页面。

再次从看板打开文档时，会建立新的详情页记录。

## 重启和重载

记录会保存到插件数据中。重启时，只恢复仍然存在、且文档路径匹配的详情页；不会自动重建不存在的详情窗口。
