# 关联文档模板

模板是仓库中已有的 Markdown 笔记。新增卡片时，插件复制其正文和属性；编辑模板仍通过普通笔记编辑器完成。

## 准备模板

例如创建 `Templates/任务模板.md`：

```markdown
---
负责人: []
优先级: 中
标签:
  - 任务
---

## 说明

## 验收标准

- [ ] 完成验收
```

模板属性应与看板展示字段对应。模板中的属性名不会根据预设或界面语言自动转换。

## 全局模板

1. 打开“设置 → Quiet Kanban → 全局新建需求模板”。
2. 点击“选择模板”，搜索并选择已有笔记；也可以直接填写仓库相对路径。
3. 未单独设置模板的看板会使用该模板。

“清除关联”只会移除全局配置，不会删除模板文件，也不会清除各看板的独立模板。

## 单个看板的模板

点击任意列的“＋ → 关联模板…”，搜索并选择模板。关联保存到当前看板视图，适用于该视图的所有列。

也可以在 Bases 视图选项中的“新建需求模板”配置。

| 情况 | 新增时使用什么 |
| --- | --- |
| 看板未配置模板 | 全局模板 |
| 看板已关联模板 | 该看板的模板 |
| 看板执行“取消关联模板” | 不使用模板，即使全局已有模板 |

## 使用模板新增

1. 点击目标列的“＋”。
2. 选择“使用关联模板新建文档”。
3. 在 Bases 原生创建界面中给文档命名并继续编辑。

属性的优先级为：

1. 当前列的分组值。
2. Bases 新建流程根据筛选等配置生成的属性。
3. 模板中的默认属性。

分组未设置的列不会继承模板里与该分组属性对应的值。其他模板属性及正文会复制到新文档。

## 打开和取消关联

“＋”菜单中的“打开关联模板”会打开源模板笔记。以后修改模板只影响后续创建，不会更新已创建的文档。

“取消关联模板”只修改当前看板的关联，不会删除模板。

## 支持范围

- 支持 Markdown 正文和对象形式的 YAML 属性。
- 模板不存在或属性格式无效时，在创建前提示并中止。
- 当前复制原始内容，不展开 `{{date}}`、`{{title}}` 等变量，也不执行 Templater 脚本。
- 模板移动或重命名后，应检查并重新关联路径。
