# 转换已有看板

本篇说明如何把 `.base` 文件中的原生 Kanban 视图转换成 Quiet Kanban。

## 转换步骤

1. 打开已有 `.base` 文件。
2. 切换到希望转换的原生 Kanban 视图。
3. 执行“Quiet Kanban: 将当前原生看板转换为增强看板（自动备份）”。
4. 等待成功提示，检查分组、字段和文档数量。

插件优先转换当前选中的原生 Kanban 视图；如果当前选中的不是原生 Kanban，会转换文件中第一个原生 Kanban 视图。没有原生 Kanban 视图时会提示，不会转换表格等其他类型。

## 保留的内容

- 原文件和其他视图。
- 筛选条件、排序及其他未涉及的配置。
- 原生分组字段和列顺序。
- 文档正文和属性。

如果原视图定义了展示属性顺序，转换后使用“跟随 Bases 属性菜单”。否则使用当前全局字段配置作为展示起点。

## 自动备份

写入前，原始文件内容会保存到：

```text
<配置目录>/plugins/quiet-kanban/backups/<时间戳>-<原文件名>.json
```

例如原文件名为 `任务看板.base`，备份文件会以 `.base.json` 结尾。

备份 JSON 包含原文件路径 `path` 和完整原始文本 `content`。转换过程中若发现原文件已被其他操作修改，会中止，避免覆盖并发修改。

需要还原时，阅读[更新与备份恢复](updates-and-backups_zh.md)。
