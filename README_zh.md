# Quiet Kanban

为 Obsidian Bases 提供可配置的看板视图，支持紧凑卡片、分组配色、模板和可复用详情页。

## 功能

- 自由选择分组和标题属性，添加、移除及排序展示字段。
- 内置任务、项目、内容和空白看板预设。
- 支持文本、标签、日期、数字和复选框，按需显示字段名或空值占位。
- 拖动列标题调整顺序，按看板自动保存。
- 在列间拖动卡片，更新可写的分组属性。
- 在卡片内快捷编辑属性，日期支持原生选择器。
- 关联全局模板，也可为单个看板独立选择模板。
- 在可复用的右侧分栏或标签页打开文档，再次点击同一卡片收起详情。
- 通过卡片菜单重命名、移动或删除文档。
- 支持中文和英文界面，默认跟随 Obsidian。

## 环境要求

- Obsidian 桌面端，版本 `1.10.2` 或以上。
- 启用核心插件 **数据库 / Bases**。

## 安装

将以下文件复制到仓库：

```text
<仓库>/.obsidian/plugins/quiet-kanban/
  main.js
  manifest.json
  styles.css
```

使用自定义配置目录时，替换 `.obsidian`。在“设置 → 第三方插件”中启用 **Quiet Kanban**。

从源码使用时，先执行 `npm run check` 构建 `main.js`。完整步骤见[安装文档](docs/installation_zh.md)。

## 快速开始

1. 创建用于存放文档的文件夹，例如 `Tasks`。
2. 右键文件夹选择“创建看板”，或执行命令“Quiet Kanban: 创建增强看板”。
3. 填写名称，选择场景预设，并设置文档所在文件夹。
4. 点击列上的“＋”新增文档或关联模板。
5. 点击卡片打开详情；开启再次点击收起后，再点同一卡片即可收起。

从文件夹右键菜单创建时，看板放在该文件夹；从命令或插件设置创建时，看板放在仓库根目录。文档所在文件夹独立控制查询范围。

## 配置

在“设置 → Quiet Kanban”配置语言、默认字段、全局模板、颜色、列宽和详情行为。

单个看板点击首列配置图标，或执行“Quiet Kanban: 配置看板字段”。选择“自定义字段列表”直接管理布局，或选择“跟随 Bases 属性菜单”使用原生字段选择和顺序。

| 预设 | 分组 | 展示字段 |
| --- | --- | --- |
| 空白看板 | 不分组 | 仅标题 |
| 任务管理 | 状态 | 负责人、截止日期、优先级 |
| 项目管理 | 负责人 | 状态、截止日期、预算 |
| 内容计划 | 发布平台 | 发布时间、标签、已发布 |

预设是可修改的起点，保存前可将属性调整为实际文档使用的名称。

拖动列标题排列列，顺序自动保存，切换文档或重新打开看板后仍保留。列内卡片顺序使用 Bases 排序。

普通笔记属性可写；公式和文件元数据只读，文件名标题通过重命名修改。按文件属性或公式分组时，不支持列内新增和拖拽写入。

## 开发

要求 Node.js 20+，无需第三方 npm 依赖。

```sh
npm test
npm run build
npm run check
```

构建、安装到已打开的仓库、重载并检查插件加载：

```sh
npm run dev:install -- --vault "/absolute/path/to/vault"
```

参数及界面测试步骤见[开发与测试](docs/development_zh.md)。

## 隐私与仓库访问

Quiet Kanban 在本地运行，不发送网络请求或遥测数据。看板数据来自当前 Bases 查询。全局字段候选来自已配置字段和场景预设，不再遍历笔记元数据；其他属性名可以直接输入。单个看板还会提供 Bases 返回的属性。

仅在打开模板选择器时，插件会列出仓库内 Markdown 文件路径，以便选择任意笔记作为模板；搜索过程不会读取笔记正文。使用关联模板创建笔记时，才通过 Obsidian API 读取该模板。文件夹建议会列出仓库内的文件夹。卡片新建、编辑、重命名、移动及删除均由你的操作触发，并使用 Obsidian API。
